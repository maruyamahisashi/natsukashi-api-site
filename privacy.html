プライバシーポリシー

最終更新日：2026年10月21日

1. 利用者

「なつかし脳トレ API」（以下「本アプリ」）は、YouTube チャンネル「なつかし脳トレ」の運営者本人だけが使う個人用ツールです。第三者の利用は想定していません。

2. 取り扱う情報

本アプリは、Google の OAuth 認証を通じて、運営者自身の YouTube チャンネルに関する次の情報にアクセスします。

  • チャンネル・動画・コメントの情報（YouTube Data API）
  • 再生回数などのアナリティクス（YouTube Analytics API）

3. 利用目的

取得した情報は、運営者が自分のチャンネルを管理する目的（コメントへの返信、動画の予約投稿、数字の分析）にだけ使います。

4. 第三者への提供

取得した情報を第三者に提供・販売することはありません。

5. 保存と削除

認証情報は運営者が管理する環境にだけ保存します。認証は Google アカウントの「セキュリティ → サードパーティのアクセス」からいつでも取り消せます。

6. Google API サービスのユーザーデータに関するポリシー

本アプリによる Google API から取得した情報の利用は、Google API Services User Data Policy（限定的な使用の要件を含む）に従います。

7. お問い合わせ

本アプリに関するお問い合わせは、Google Cloud のアプリ情報に記載のサポート用メールアドレスまでお願いします。
